Dot

Dot is a native macOS floating companion. Click to talk, click again to interrupt. English transcription runs locally with Whisper, the voice is a local Kokoro helper, and screen context is used only for the conversation you started. The Qwen3.8 27B Q4 model runs on your Mac.

AccessProof

AccessProof runs the vendored axe-core engine locally in your browser. It checks pasted HTML for WCAG A/AA failures, adds best-practice advice, and flags common overlay signatures — without uploading the markup.

Locale

Locale is a local-only review desk for multilingual releases. A Rust core validates coverage and binds decisions to evidence fingerprints; the same core runs as a native CLI or WebAssembly in the browser. The demo project is synthetic.
